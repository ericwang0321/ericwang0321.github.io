1. 核心结论

内存市场正在从一个“消费电子周期品”变成“AI 基础设施瓶颈资产”。JPMorgan 将 2026E/2027E/2028E memory revenue 预测上修到 US$936.3bn/US$1,363.6bn/US$1,691.3bn，原因是 GPU 以外的 CPU orchestration、server DDR/LPDDR、HBM、enterprise SSD 都在同时拉动需求。[S01 p.18] Goldman Sachs 的框架更聚焦 HBM，预计 HBM TAM 从 2026E 的 US$55.8bn 升至 2027E 的 US$116.3bn、2028E 的 US$168.4bn。[S02 p.13]

产品上，最重要的分层是 HBM、server DDR/LPDDR、NAND/eSSD，而不是传统的 DRAM/NAND 二分法。HBM 解决 AI training 和高端 accelerator 的带宽瓶颈，GS 预计 ASIC 占 HBM demand 的比例从 2026E 的 33% 升至 2028E 的 39%。[S02 p.13] Server DDR/LPDDR 则被 AI CPU、headnode、推理编排和 agentic AI 拉动；JPM 预计 FY27E/FY28E AI CPU DRAM demand 为 11mn/17mn GB，占 total market demand 的 19%/24%。[S01 p.1] NAND 的核心增量是 enterprise SSD，JPM 预计 eSSD 2026E 超过 500EB，占 total NAND bit demand 的 43%，未来两年超过 1,100EB，CAGR +52%。[S01 p.2]

公司上，DRAM/HBM 是 Samsung、SK Hynix、Micron 三强；NAND 还包括 Kioxia、SanDisk/Western Digital、YMTC。GS 预计 Hynix/Samsung/Micron 在 HBM 的 2026E 份额为 44%/33%/23%，2028E 为 42%/37%/21%。[S02 p.14] 国信引用 IDC 的 1Q26 DRAM share 为 Samsung 32.5%、Micron 22.3%、SK Hynix 18.5%、CXMT 7.5%；NAND share 为 Samsung 38.7%、SK Hynix 29.1%、Kioxia 14.4%、SanDisk 14.0%、Micron 13.9%、YMTC 6.8%。[S07 p.20]

Source: S01 p.18, JPM Global Memory Model.

4. 为什么这一轮不只是周期涨价

供给侧短缺是真实的，但需求结构变化更关键。GS 预计 2026E/2027E/2028E DRAM industry S/D 为 -5.0%/-5.9%/-3.9%，NAND S/D 为 -4.4%/-4.6%/-3.0%，HBM S/D 为 -5.4%/-6.0%/-4.3%。[S02 p.10-p.13] 这意味着传统 DRAM、NAND、HBM 同时偏紧，而不只是某一个产品短缺。

需求端的变化有三条线：

变化 机制 数据证据
GPU/ASIC 拉 HBM HBM 与 accelerator 绑定，ASIC 需求占比上升 GS 预计 ASIC HBM demand share 从 2026E 的 33% 升到 2028E 的 39%。[S02 p.13]
CPU 拉 server DRAM AI orchestration、API execution、state management 需要 CPU memory JPM 预计 CPU-to-GPU ratio 从 2023 年 5.4:1 到 2025 年 3.2:1，再到 2028E 的 2.4:1，推动 FY27E-FY28E server-grade DDR/LPDDR5 bit demand 上修 20%-22%。[S01 p.1]

5.2 DRAM

DRAM 仍是三强市场，但 CXMT 开始进入全球份额表。国信引用 IDC 的 1Q26 DRAM share 为 Samsung 32.5%、Micron 22.3%、SK Hynix 18.5%、CXMT 7.5%、Nanya 1.6%、Winbond 0.5%。[S07 p.20] Bloomberg/Gartner 的 3Q25 volume basis 则为 Samsung 35.9%、SK Hynix 29.0%、Micron 22.4%，三家合计 87.2%。[S08 p.17] 两组数据口径和时间点不同，方向一致：头部集中，但中国供应份额上升。

JPM 对中国 DRAM 更偏中期：预计中国 DRAM volume share 从 2025 年 6% 升至 2026E-2028E 的 8%-11%，但 value share 到 CY28E 只有 10%，说明产品结构仍偏传统/低价值段。[S01 p.2]

5.3 NAND

NAND 比 DRAM 更分散。国信/IDC 的 1Q26 NAND share 为 Samsung 38.7%、SK Hynix 29.1%、Kioxia 14.4%、SanDisk 14.0%、Micron 13.9%、YMTC 6.8%。[S07 p.20] Bloomberg/Gartner 的另一组 volume basis 口径为 Samsung 26.2%、SK Hynix+Solidigm 20.8%、Kioxia 17.8%、Sandisk 和 Micron 为 low-teens。[S08 p.17] 差异很大，说明 NAND 份额表要特别注意“bit / volume / revenue / quarter / Solidigm 是否并表”的口径。

JPM 对中国 NAND 的中期预测是：NAND volume share 从 2025 年 12% 到 2026E-2028E 的 12%-16%，CY28E value share 约 12%。[S01 p.2]

7. 服务器 BOM：为什么内存变成系统约束

传统 CPU server 的 BOM 对内存/存储更敏感。GS 的例子中，dual CPU general server 总成本 US$6,678，ASP US$8,000，OEM gross margin 17%；其中 RAM 1TB 成本 US$267，占 BOM 4%，storage 12 x 512GB SSD 成本 US$1,800，占 BOM 27%。[S05 p.14] 但 GS 同时指出，DRAM/NAND 传统上约占 traditional server BOM 的 30%，在 2026/2027 涨价预期下，某些配置中 memory 可超过 BOM 的 60%。[S05 p.1, p.14, p.24]

AI server 的直接 BOM 更被 GPU 主导。GS 的 H100 DGX server 例子中，GPU baseboard 成本 US$206,780，占 BOM 86%；RAM 2TB 占 0.8%，storage 占 1.2%，总成本 US$241,114，ASP US$265,000，OEM gross margin 9%。[S05 p.18] 这意味着 AI server 对 HBM 的经济暴露很多时候已经包含在 GPU/accelerator 价格中，而 traditional server 对外采 DRAM/NAND 价格更敏感。

8. 投资和产业含义

第一，HBM 的价值不仅是收入，而是产能机会成本。GS 认为 HBM consumes 3-4x more wafer capacity versus conventional DRAM，并因此限制 conventional memory supply growth。[S02 p.5] JPM 也预计 60% 的新增 DRAM WSPM 会分配给 HBM，导致 conventional DRAM 更紧。[S01 p.2]

第二，eSSD 是被低估的 NAND 增量。JPM 预计 eSSD 2026E 超过 500EB，未来两年超过 1,100EB，value TAM 未来两年可能超过 US$300bn。[S01 p.2] GS 同时预计 eSSD demand 2026E/2027E 增长 66%/31%，达到全球 NAND demand 的 38%/42%。[S02 p.11]

第三，国产厂商的机会主要在份额窗口，而不是立即抢走高端利润池。JPM 预计中国 DRAM/NAND volume share 到 2026E-2028E 分别为 8%-11%/12%-16%，但 value share 到 CY28E 只有 10%/12%。[S01 p.2] 这意味着国产替代的第一阶段更像“传统/利基产品填补 + 本土客户导入”，高端 HBM/HBM4E/enterprise SSD 仍需要技术和客户认证。

第四，系统厂的压力和芯片厂的利润是同一枚硬币。GS 指出 server vendors 可能无法完全满足 backlog/demand，并且 Dell 等 server vendor 有 2026 年涨价超过 50% 的报道；这对芯片厂是 ASP 和 LTA 支撑，对 OEM 是毛利和需求弹性的挑战。[S05 p.25]
